# Scratch

This directory is scratch space: throwaway, short-lived, and unbacked. Assume anything here can be deleted after a few days. Treat it as a workbench for experiments, drafts, prompts, one-off scripts, and intermediate output.

## Task directories

1. At the start of each task, create `YYYY-MM-DD-<task-slug>/` using today's date and a short kebab-case slug (e.g. `2026-09-25-cardinality-canary/`).
2. Put every file for that task inside it.
3. When the task continues on a later day, keep working in the original directory under its start date.

Stay inside your own task directory. Leave other directories and top-level files as you found them. If present, `archive/` holds loose files from before this convention; read from it, and write new work to a task directory.

## Durability

Move anything worth keeping to a permanent home (a repo, a doc, a gist) before calling the task done, and tell the user where it went.
