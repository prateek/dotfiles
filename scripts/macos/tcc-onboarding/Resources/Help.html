Review your app permissions

Dotfiles Permissions compares the permissions in your inventory with macOS records. You make every change in System Settings.

Allow permission checks

The helper needs Full Disk Access to read macOS permission records. Open Privacy & Security → Full Disk Access, add the helper, and enable it. Relaunch the helper if the records remain unreadable. macOS grants broad disk access; this helper uses it to read permission records and never changes them.

Review an app

The checklist groups permissions by app. Select a permission row to expand its reason, recorded status, and next steps inline. The filter switches between unresolved permissions and the full inventory. Press ⌘R to check again.

This single window stays available above System Settings while you review access. Move it beside the permission list to drag the exact target. It returns to its normal window level when you switch to another app. Use the Dock, ⌘Tab, or View → Show Permission Inventory to return.

Add the exact app

For Accessibility, Input Monitoring, and Full Disk Access, drag the entire file tile into the permission list and enable the entry. Show in Finder opens the exact subject. The File menu offers Copy Path and exact-path keyboard help; where Settings provides an add (+) button, use it, press ⌘⇧G in the file chooser, and paste that path. A declared helper executable may differ from the enclosing app bundle.

Microphone and Camera access must be requested by the target app. Open the app and use the relevant feature. Screen Recording currently uses its Settings entry and the app’s own request; no drag instruction is offered.

Understand the status

  • Allowed in macOS: the recorded grant matches the installed code. An app may need to restart before adopting changes.
  • Not allowed: macOS records a denial.
  • Needs reauthorization: the saved permission does not match this installed copy. Follow the visible removal and re-add instructions where the service permits.
  • Needs review: evidence is missing, unreadable, conflicting, unsupported, or unverifiable. Check the app’s Settings entry and Technical Details.
  • Not installed: no matching app or declared helper exists; no grant is requested.

Recorded state does not prove an app’s features work. The helper never resets permissions or automates Settings switches. Later leaves access unchanged.
