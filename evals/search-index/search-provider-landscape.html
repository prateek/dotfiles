“URL found” counts core queries with at least one returned URL. It does not say whether the link works or helps answer the question. Degoog's Bing/DDG/Reddit mix returned URLs for every core query but missed all nine requested platform domains; Startpage supplied eight. Its Startpage + Brave API bundle found the requested URL shape in 9/9 platform probes, but sends every search to the same paid Brave index as the direct API. Brave HTML scraping found 3/9 before upstream 429. OpenSERP OSS counts are B = Bing, D = DuckDuckGo, G = Google, each out of 27.

What price cannot tell us yet

We have measured access, returned URLs, and some latency. We have not completed blinded relevance grades or full agent tasks.

Cost per useful result = search cost ÷ links that actually help the task. A $0.005 search with ten links costs $0.0005 per returned link. If only one is useful, it costs $0.005 per useful link.

GitHub is its own lane

Native GitHub search and grep.app MCP passed focused repo/code probes. We still need to score exact files, revisions, issues, and comment links.

Social and shopping need source checks

A web result can find a Reddit thread or Amazon URL. It cannot prove a full comment, current offer, or address-specific delivery. These checks are documented in the source-access matrix.
