# last30days

Publishes the self-contained upstream skill at `v3.23.0`, pinned in the root APM
lock to `1f378527b229ffcb00102b6440e49fa06c582443`. Its script paths resolve
relative to the loaded `SKILL.md`, including native `prateek-local` caches.

`licenses/mvanhorn/last30days-skill/LICENSE` is an unchanged copy of the root
MIT license from that same release. It is retained here because APM's skill
subdirectory acquisition omits it; acquiring the whole repository would include
an unsupported standalone MCP component.
