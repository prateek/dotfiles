# Draft with the user

Use this branch when the user requests guided coauthoring, section-by-section
work, or iterative selection among alternatives. Honor their section order,
feedback style, and requested pauses.

Read supplied context before asking questions. Ask only for remaining decisions,
and scale each batch to the uncertainty. A user can answer briefly, paste notes,
or edit the document directly. Continue independent drafting while waiting when
that is useful and consistent with the requested pause.

For the section being developed, identify its job, propose useful options when
there is a real choice, then draft from the selected direction. Carry preferences
forward. On feedback, update the affected section and any consequences elsewhere.
Reread direct user edits before continuing; preserve them and reconcile the draft
around them. Finish a section when it meets its purpose and the user's stated
conditions for moving on.

Use the host's available document tools. When an image or source is inaccessible,
record that specific limit and request the missing content only if it is needed.
Do not assume a provider-specific tool, connector, or inability.

Return to the entrypoint's reader review when the draft is coherent. Further
iteration is driven by concrete gaps or the user's preference, without fixed
question counts, brainstorming quotas, review percentages, or a compulsory final
approval question.
