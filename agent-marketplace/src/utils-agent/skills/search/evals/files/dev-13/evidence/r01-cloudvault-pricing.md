Source: cloudvault.example/pricing (official, updated 2026-09)
CloudVault Cold: $1.00 per TB per month, billed per TB stored. 4 TB = $4.00/month.
No egress, API-request or minimum-duration fees. S3-compatible API.
Restores work with any S3 client (rclone, Cyberduck, aws cli).
CloudVault provides no backup software; you bring your own client.
