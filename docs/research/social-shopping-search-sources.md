# Social and shopping search access

Source review as of 2026-09-27. This maps **searchable access**, not whether a provider's first live query returns useful results. The existing [search evaluation](search-index-eval.md) contains historical social cases, but it has no representative historical shopping cases. The [18 platform probes](../../evals/search-index/platform-probes.jsonl) are synthetic and explicitly labeled; they are not mined from user sessions.

## Social and forums

| Source | Native access and gate | Evaluation route |
| --- | --- | --- |
| Reddit | Reddit documents a post search endpoint and requires OAuth for its Data API. Eligible free API access is limited to 100 queries/minute per OAuth client ID averaged over 10 minutes; unauthenticated traffic is blocked. Its terms require approval for commercial uses or research beyond limits and constrain retention/deletion. [API reference](https://www.reddit.com/dev/api/#GET_search), [Data API wiki](https://support.reddithelp.com/hc/en-us/articles/16160319875092-Reddit-Data-API-Wiki), [terms](https://redditinc.com/policies/data-api-terms). | Compare OAuth native post search against web provider `site:reddit.com` discovery. Fetch canonical thread/comment URLs separately. Score thread discovery and evidence extraction separately; a web result snippet is not a full thread. |
| Hacker News | The [official HN API](https://github.com/HackerNews/API) is free, requires no key, and provides item IDs/content and feeds, but no text search endpoint. [HN Search](https://hn.algolia.com/about) is an Algolia-hosted index built from that official API; its [public search API](https://hn.algolia.com/api) is the practical no-key search route. | Use HN Algolia for keyword and date search, then the official API or canonical HN page for item/comment detail. Compare with web `site:news.ycombinator.com` search. |
| YouTube | [Data API `search.list`](https://developers.google.com/youtube/v3/docs/search/list) searches videos/channels/playlists and supports date, region, and type filters. Google Cloud API key/OAuth and quota are needed. Google's [current quota overview](https://developers.google.com/youtube/v3/getting-started) says the default allocation is 100 `search.list` calls/day; `search.list` moved to its own quota bucket in June 2026. | Native discovery followed by `videos.list` for metadata; compare with web `site:youtube.com` discovery. For a case about a specific claim in a video, title/description discovery alone is insufficient: score transcript or video evidence as a separate retrieval stage. |
| X | [Recent Search](https://docs.x.com/x-api/posts/search/introduction) covers seven days; full archive search is pay-per-use/Enterprise. A developer account, project/app, and tokens are required. [Pricing](https://docs.x.com/x-api/getting-started/pricing) is credit-based; its published Post read rate is $0.005 per returned Post, with current prices in the console. | Test web `site:x.com` discovery first for old posts. Add the native API only if cases require timely or archive-complete X evidence; constrain returned count and spending. Label web coverage as incomplete, especially for fresh posts and replies. |
| Facebook Marketplace | Meta describes Marketplace search as a consumer feature in its [Marketplace announcement](https://about.fb.com/news/2026/03/facebook-marketplace-new-meta-ai-tools-make-selling-faster-and-easier/). I could not verify a public, self-serve buyer-side Marketplace listing search API in Meta's developer documentation. That is an evidence limit, not proof that no partner or research route exists. | Treat location-aware Marketplace search as a distinct **browser/manual or specialist-provider** lane. Test web indexed listing URLs only as partial discovery; require listing URL and live price/availability verification in Marketplace. Do not score a general web provider as though it had full local Marketplace inventory. |

## Shopping and delivery

| Source | Native access and gate | Evaluation route |
| --- | --- | --- |
| Amazon | The supported [Creators API `SearchItems`](https://affiliate-program.amazon.com/creatorsapi/docs/en-us/api-reference/operations/search-items) searches Amazon catalog items, up to 10 per request, and can return offer price. [Registration](https://affiliate-program.amazon.com/creatorsapi/docs/en-us/onboarding/register-for-creators-api) requires a finally accepted Amazon Associate who has referred qualifying sales; it is not an instant general search key. Amazon says legacy PA-API 5 is [deprecated](https://affiliate-program.amazon.com/creatorsapi/docs/en-us/paapiv5-deprecation). | Use web `site:amazon.com` for discovery during this evaluation, then verify ASIN, offer, price and delivery on Amazon. Mark Creators API as gated until legitimate Associates eligibility exists. Web snippets are not a current price/stock oracle. |
| Alibaba.com | Alibaba's international B2B open platform lists [`alibaba.icbu.product.list`](https://developer.alibaba.com/docs/api.htm?apiId=25438), but its description is a seller-authorized product-list/query API. The [ICBU search category](https://developer.alibaba.com/docs/api_list.htm?cid=20963) did not reveal a general public buyer catalog search endpoint in this review. These docs do not establish unrestricted Alibaba.com marketplace search. | Use web indexed supplier/product pages for discovery and verify quote, minimum order quantity, supplier, ship-to country and currency at the source. Keep AliExpress and Taobao APIs out of the Alibaba.com lane; they are different marketplaces. |
| Uber Eats | Uber's [Eats Marketplace APIs](https://developer.uber.com/docs/eats/introduction) cover merchant stores, menus, and orders. [Getting started](https://developer.uber.com/docs/eats/guides/getting-started) calls for an NDA, API licence and partner approval; Uber says consumer discovery/search/cart building is handled by Uber, before a merchant order integration begins. [Order journey](https://developer.uber.com/docs/eats/guides/order-integration). | Test web restaurant/menu discovery as a weak fallback, then check the consumer site/app at a fixed delivery address and time. Exclude merchant APIs from a buyer search benchmark. |
| Instacart | The [Developer Platform](https://docs.instacart.com/developer_platform_api) advertises retailer and product discovery, while [getting started](https://docs.instacart.com/developer_platform_api/get_started/overview/) requires access application and says access-to-demo/production integration averages 30–40 days. Its [MCP search](https://docs.instacart.com/mcp_servers/get-started/get-started-overview) is also partner-provisioned. | Test web product/store discovery as partial. A native lane is possible only after Instacart access; then evaluate product availability, store, delivery ZIP, and price with the same address/time fixture. |

For a first coverage suite, use one or two prompts per source, with explicit `source`, `intent`, `geography`, `currency`, `delivery_address_context`, `as_of`, and expected canonical evidence. Cover exact-item lookup, comparative discovery, and live availability/price as separate intents. Freeze a source snapshot or judge live evidence at the same time for every configuration; shopping results can change by account, address, stock, promotion and time. Keep three outcomes distinct: found a candidate URL, extracted source evidence, and satisfied the full shopping constraint. Web search can legitimately win the first while failing the latter two.
