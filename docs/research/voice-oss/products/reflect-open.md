# Reflect Open: local notes, voice capture and composability

Reflect Open is a strong additional reference for this project because it connects audio memos to a daily-note and backlink system while keeping Markdown and audio files under the user's control. Its CLI, optional iCloud, owned Git remotes and provider settings make it especially useful for the second-brain and composability requirements. This is an assessment of fit, not a measured ranking of transcription accuracy, reliability or Apple design quality.

This inventory contains **25 flows and 32 primary sources**, researched on **2026-10-12**. DOCUMENTED means an explicit first-party procedure or release record; SOURCE-DERIVED means inspected public source at commit `eb12782688b8bcec08125d27566b0616831f67fe`; MARKETING means a publisher claim; UNKNOWN means this inspection did not settle the question. No app, user account, microphone, private graph or paid service was exercised. The public MIT repository was cloned into ignored research scratch. This is source inspection, not REA binary analysis or proof of packaged runtime behavior.

## Product identity and release boundary

**Reflect Open and Reflect Classic are distinct products.** The current official homepage leads with Open: local Markdown, free Mac application and subscription-backed iPhone/iPad application. Classic remains maintained and separately billed; migration imports a copy. Open does not inherit every Classic capability, account architecture, AI entitlement or calendar integration. [Current product](https://reflect.app/), [pinned README](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/README.md).

The current App Store listing is explicitly **Reflect Open**, supports iPhone/iPad from iOS/iPadOS 16, and lists a US yearly purchase of $99 at access time. Mac App Store compatibility is not evidence that the mobile binary is the supported desktop experience. Desktop downloads have Apple Silicon and Intel variants. The repository still calls the project beta and directs iOS users to TestFlight, while the homepage and Apple listing provide ordinary App Store distribution. Record this as documentation drift, not a reason to call Open unreleased. Observed desktop release channels were stable **0.14.0** (September 29) and prerelease **0.15.0-beta.7** (October 9). The pinned development commit is a separate source boundary; source-only findings below are not asserted to be in either package. [Apple listing](https://apps.apple.com/us/app/reflect-open/id6787385615), [releases](https://github.com/team-reflect/reflect-open/releases).

The repository uses a Tauri/Rust host with a React/WebView editor and Swift native iOS recording/widget pieces. Apple platform integration does not establish an all-Swift native UI, nor has this study judged its interaction quality hands-on. Source is MIT licensed; that does not grant rights to Classic, branding or hosted services. [Repository layout](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/README.md), [license](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/LICENSE), [native recorder](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/plugins/tauri-plugin-recording/README.md).

## Voice, meeting integration and provenance

The inspected Mac recorder calls `getUserMedia({audio: true})` and uses `MediaRecorder`. The iOS implementation uses `AVAudioRecorder` to stage AAC files outside the WebView, then imports completed segments into the graph. This establishes microphone memo capture, including spoken or in-person meeting notes. It does **not** establish system-audio capture of a remote Zoom/Meet call. Bounded searches across desktop frontend, Rust host and core source for Zoom, Meet, diarization, speaker, system-audio, ScreenCapture, CallKit, WatchKit and MCP did not establish an active-speaker, participant-identity or conferencing SDK pipeline. Incidental matches concerned image zoom and prose. Calendar attendee links are separate metadata, not speaker attribution. [Mac recorder](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/apps/desktop/src/hooks/use-audio-recorder.ts), [native recorder](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/plugins/tauri-plugin-recording/README.md), [calendar boundary](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/docs/porting/calendar-meetings-integration.md).

The voice pipeline saves original segments before transcription and writes the resulting note before its daily backlink. Network failures leave pending audio; local-save failures hold the queue behind Retry/Discard. Session reconstruction waits for contiguous, locally downloaded parts. Successful per-part recognition results are cached to avoid paying again when a later part fails. These are useful mechanisms for recoverability, but not immutable derivation history. The current segment rotates every **20 minutes**; the native plugin explicitly acknowledges that a crash before finalization can lose the active segment. The desktop path also buffers the active segment in memory. This is a concrete gap against the user's strict retention ambition. [Capture and reconciliation](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/packages/core/src/actions/audio-memo.ts), [session semantics](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/packages/core/src/actions/audio-memo-session.ts), [save queue](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/apps/desktop/src/hooks/use-audio-memo-pipeline.ts).

Transcription is distinct from chat provider choice. The inspected selection allows only OpenAI or Google for audio, and the recognition implementation uses fixed provider endpoints and plain-text results. The current source's OpenAI-compatible endpoint form can route **chat** to an owned local or remote server; it does not automatically make transcription local. Retained files make external reprocessing possible, but the app's regeneration path can reuse cached part results. A built-in command that forces a new model, preserves old edited transcripts and records model/prompt lineage remains unestablished. [Transcription selection](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/packages/core/src/ai/provider-config.ts), [transcription implementation](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/packages/core/src/ai/transcribe.ts), [chat model factory](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/packages/core/src/ai/language-model.ts).

## Ownership, automation and limits

The file graph is the durable product boundary: daily and named Markdown, attachments, audio memos and templates remain useful independently of the app. SQLite and derived transcript caches under `.reflect/` are local runtime state. The CLI offers predictable graph selection, stable JSON, data-only stdout, explicit failure codes and private-note checks against current files. It is read-only; ordinary file edits provide a separate write path. Deep links add only narrow daily captures or navigation, and browser capture uses a local native-messaging inbox with retry. This is a useful composability model, though native MCP, hook dispatch and XDG configuration contracts were not established. [CLI](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/docs/cli.md), [deep links](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/docs/deep-links.md).

Owned SSH Git remotes or a bare repository on storage can support self-operated backup without a Reflect service. That is not equivalent to a packaged multi-user server deployable on exe.dev or Unraid. iCloud is an optional alternative per graph, not a second concurrent sync engine. Conflict archives are finite, and upstream's Git safety document names pending or ignored cases involving concurrent writes, interrupted merges and unsaved editor state. Treat its guarantees as a contract to inspect and test, not evidence of universal data-loss prevention. [Owned Git remotes](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/docs/generic-git-remotes.md), [iCloud](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/docs/icloud-sync.md), [safety gaps](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/docs/git-backup-safety.md).

The private flag is a service-access policy, not encryption or an operating-system boundary. It excludes note content from supported AI/CLI paths while allowing the user's own Git backup to retain the note. A new recording and its fresh transcript may still go to configured providers even when the daily note is private. Official builds also send described scrubbed diagnostics to Sentry. Do not turn local-file storage into a claim of zero network traffic. The privacy document's blanket server inventory deserves further reconciliation with release notes that mention a YouTube relay; this study did not trace that unrelated media route. [Privacy](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/docs/privacy.md), [release notes](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/apps/desktop/CHANGELOG.md).

## What to learn for the proposed project

**Analysis, not accepted requirements:** connect recordings to daily/project/person context without hiding their original files; make AI output an inspectable, replaceable derivative; expose both a friendly note UI and predictable scripting contracts; separate local capture from asynchronous provider processing; preserve failed work visibly; and show sync conflicts as recoverable user states. Reflect's explicit distinction between template files, selection AI prompts and note-grounded chat is particularly useful for a composable second brain.

The proposed product would still need its own design for reliable Zoom/Meet audio and speaker observations, custom iOS keyboard, Watch capture, ordinary-number telephony, local transcription, hooks/MCP/XDG, original audio replay with derivation versions, and quantified durability under crashes or full disks. This review found no evidence establishing those complete flows in Reflect Open. Broader desktop system dictation, multi-user collaboration, every mobile permission/keyboard interaction, all import/export fidelity, accessibility, multilingual recognition and packaged-release/source parity remain outside this inventory. Deleting a regular Mac note uses system Trash and excludes daily notes from that action; permanent retention and cross-device deletion behavior need separate validation. [Trash implementation](https://github.com/team-reflect/reflect-open/blob/eb12782688b8bcec08125d27566b0616831f67fe/apps/desktop/src/components/context-sidebar/note-trash-action.tsx).
