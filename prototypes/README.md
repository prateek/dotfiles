# Prototypes

Throwaway, self-contained HTML prototypes built to answer one question each
(the `prototype` convention: a pure logic module plus a thin page over it).
They are not production code and do not belong on `master`; once a
prototype's question is settled, its verdict is folded into the owning doc
and the file moves to a scratch branch. They live here rather than under
`docs/` because `docs/` is Markdown only.

| File | Question | Owning doc |
| --- | --- | --- |
| `nix-target-state-alternatives.prototype.html` | Which combination of substrate, work-Mac shape, composition, co-owned-file policy, plist mechanism, secrets, CI, and Homebrew stance holds up across our five hosts? | [Nix Target-State Research](../docs/research/nix-target-state-research.md) |
| `nix-composition-alternatives.prototype.html` | Which of eight composition models makes the daily operations (add an app, add a host, rename, overlap, retire) cheap and loud rather than silent? | same, "Composition model" |

Open a file by double-clicking it; nothing to install.
